## ProjectTrack </br>
```A Code and Facet Bug /Issue Tracker, and Developer Assignment Roster```</br>

---
This tool was created for us so that we could keep track of issues locally. The idea is so we can organize our team workflow without forgetting our overall agenda.
The roster is exportable and can be uploaded to any website.
